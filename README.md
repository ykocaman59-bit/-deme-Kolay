# Ödeme Kolay

Ödeme kanallarına hızlı erişim sağlayan, ödeme işlemini kendi içinde gerçekleştirmeyen React + Vite arayüzü.

## Çalıştırma

Node.js kurulu bir bilgisayarda:

```bash
npm install
npm run dev
```

Üretim için:

```bash
npm run build
```

## GitHub

Bu klasörü bir GitHub repository'sine yükleyebilir veya ZIP dosyasını açıp dosyaları repository'ye aktarabilirsin.

## Önemli

Bu proje örnek/başlangıç uygulamasıdır. Yayına almadan önce her kurum için kullanılan bağlantıların güncel ve resmî olduğunu kontrol et. Marka/logoların kullanım koşullarını ayrıca incele.
